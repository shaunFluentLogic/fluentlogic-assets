# FluentLogic assets

Static brand assets served via GitHub Pages at `https://assets.fluentlogic.com`.

## URL scheme

- Logos: `https://assets.fluentlogic.com/logo/<filename>`

## Current assets

- `logo/fluentlogic-logo.png` — primary company logo (source: 300mm @ 300dpi print master; web-sized variants pending)

## Adding new assets

1. Place the file under the appropriate folder (`logo/`, `icons/`, etc.).
2. Use lowercase, hyphenated filenames (`fluentlogic-logo.png`, not `FluentLogic_Logo.PNG`).
3. Commit to `main` — GitHub Pages redeploys automatically.
